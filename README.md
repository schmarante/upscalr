  <b>UPSCALR</b>

AI upscaling and background removal for photos, drawings and illustrations – right in your browser.

**PNG · JPEG · WebP · AVIF · GIF · BMP · 2× / 4× · background removal**

<a href="https://schmarante.github.io/upscalr/"><img src="https://img.shields.io/badge/%E2%96%B6%20Live%20demo-schmarante.github.io%2Fupscalr-2ea44f?style=for-the-badge" alt="Live demo"></a>

Drop an image into the window, pick photo or drawing and get a sharp, enlarged version in seconds. Everything runs locally on your GPU – **no upload, no server, no install. Your images never leave your computer.**

## Highlights

- **Runs on your graphics card (WebGPU)** – half-precision models where the GPU supports them; without WebGPU it falls back to the processor (multi-threaded WebAssembly), just slower.
- **Photos and drawings** – a fast and a high-quality model for photos, one for drawings, anime and line art.
- **Background removal** – on its own or together with upscaling; the result keeps its transparency (PNG when the original format has none).
- **Large images without seams** – processed in overlapping tiles that are blended smoothly; tiles shrink automatically when graphics memory runs short.
- **Before/after slider** with zoom and pan, pixel-sharp from 300 %.
- **Same format out as in** – the result is saved as `<name>-upscale.<ext>`; transparency is kept.
- **Works offline** after the first run – models are cached in the browser.
- English and German UI.

**Browser:** current Chrome or Edge recommended (WebGPU). On static hosting like GitHub Pages a small service worker enables cross-origin isolation for the multi-threaded fallback; on your own server `public/.htaccess` sends the headers.

## Build

```sh
npm ci
npm run models:fetch   # the converted models from this repository's release (public/models/)
npm run build          # → dist/
```

The models are converted by our own converter (`scripts/convert-models.mjs`, nothing but Node: the checkpoints are read and rebuilt as ONNX graphs) and published as a release of this repository – neither the build nor the browser fetches anything from third-party servers. `npm run models` converts them yourself from the published checkpoints; only needed after changing `scripts/models.json` or the converter (the next deploy then publishes a new release).
